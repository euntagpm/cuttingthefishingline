# 낚시줄끊기 — 브라우저 확장 (Chrome MV3)

웹(B)에서 효용을 본 뒤 일상 탐색에 잇는 **연속 경로(B → A)** 입니다. 활성 탭 URL을 읽어 동일한 분석 API를 호출하고, 사이드 패널에 갭/FOMO/가격대/용어/대안을 정리합니다.

## 설치 (개발)

```bash
npm run ext:build
```

1. Chrome → `chrome://extensions`
2. 우상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → `extension/dist` 선택
4. 확장 아이콘 → 팝업에서 **API 주소** 입력 (예: `http://localhost:3000`)
5. 분석할 페이지에서 **이 페이지 분석** 클릭

## 권한 정책

- `activeTab` — 사용자가 버튼을 누른 그 탭의 URL만 사용
- `sidePanel` — 사이드 패널 표시
- `storage` — API 주소 저장
- `host_permissions` 비어 있음 — 무차별 페치/주입 없음

분석은 **브라우저가 아닌 백엔드**에서 사용자가 명시적으로 보낸 URL에 한해 수행됩니다. 페이월·로그인 콘텐츠 무단 수집은 비목표입니다.
