## Part A — PRD (Product Requirements Document)

### A.1 한 줄 요약

대한민국에서 고가·FOMO 마케팅이 심한 **강의/부트캠프 랜딩 URL**을 유저가 **직접 붙여넣으면**, 제품이 **마케팅 vs 실제 학습 범위**, **FOMO 문장 분리**, **용어·커리큘럼 풀이**, **무료·저가 대안 루트(유튜브·인프런·아티클 등)** 를 **중립적 신호**로 보여 주고, **구매 결정은 항상 유저**에게 남긴다.

### A.2 배경 / 기회

- 사회적 인식: “강의팔이”, 과대 마케팅, 알맹이 없는 고가 강의에 대한 불신이 큼.
- 유저 여정: 광고 → FOMO → 랜딩 → 생소한 용어로 불안 + 필요 동시에 느낌 → **가격**으로 망설임.
- 기존 대안: 스스로 유튜브·인프런·글을 찾아야 하며, **랜딩 문장과 대조**하기 어렵다.

### A.3 제품 형태 (확정)

| 구분 | 설명 |
|------|------|
| **B — 온보딩 웹** | 단독 웹. URL 붙여넣기 → 해당 URL 로드 → **사이드 패널**에서 분석·표시. **효용 체감의 진입점.** |
| **A — 브라우저 확장** | B에서 가치를 본 뒤 설치·연속 사용. **구체 권한(탭 읽기 범위 등)은 구현 단계 명세.** |
| **순서** | **B → A** (먼저 단독으로 신뢰·효용, 이후 확장). |

### A.4 핵심 가치 / 원칙 (비기능 포함)

- **신호만 제공:** 갭, FOMO 문장, 대안 링크. **판사·일방적 “쓰레기” 단정 금지.**
- **유저 개시 데이터:** 최소한 **붙여넣은 URL** 기반 페치; 무단 유료 본문 크롤·재배포 비목표.
- **면책:** “참고용 신호, 구매는 본인 책임”에 준하는 UI 카피.

### A.5 사용자 시나리오 (PRD 수준)

1. 유저가 SNS/검색 광고 등으로 **특정 강의 랜딩 URL**을 갖고 있음.
2. **온보딩 웹**에 URL 붙여넣기 → 페이지 로드.
3. **사이드 패널**에서 (1) 마케팅 주장 vs 커리큘럼/학습 범위 **갭**, (2) FOMO 조장 문장 **별도 목록 + 짧은 근거**, (3) 가격이 높을 때 **용어·커리큘럼 풀이** 및 **무료·저가 루트** 비중 강화, (4) 유튜브·인프런·아티클 등 **외부 링크** 제안.
4. 유저는 **스스로** 결제 여부를 결정. 필요 시 **확장 프로그램** 설치로 이후 탐색 시 동일 패턴 지원(연속 경로).

### A.6 범위 (In / Out)

**In**

- 공개 URL 기반 텍스트/메타 분석(구현 시 기술 선택).
- 사이드 패널 UI, FOMO 구역, 갭 요약, 대안 링크 모듈.
- 가격 입력 또는 페이지에서의 가격 추출(가능 시) 및 **가격대별 UI/추천 가중치 정책** 문서화.

**Out (Non-goals)**

- 특정 강사·플랫폼 비방, 법적 자문 대행.
- 로그인·페이월 뒤 콘텐츠 무단 수집.
- “무료가 항상 정답” 시스템 결론.

### A.7 기능 요구사항 (요약)

| ID | 요구사항 |
|----|----------|

| FR-3 | FOMO 유발 문장 **분리 표시** + 중립 톤 + 짧은 근거. |
| FR-4 | 가격/가격대 반영 시 **고가**에 용어 풀이·무료·저가 루트 가중. |
| FR-5 | 유튜브·인프런(또는 유사)·아티클 링크 제시. |
| FR-6 | 면책·중립 문구. |

### A.8 수용 기준 (체크리스트)

- 갭 / FOMO 분리 / 가격대 정책 / 외부 링크 / 면책 / A 연속 경로 스펙화.

## Part B — Working Backward (완성된 미래 시나리오)

아래는 **출시 후 성공한 세계**를 가정한 **보도자료 스타일 + 하루 시나리오**이다.

### B.1 가상 보도자료 (Press Release 요지)

**서울, 2027년 ○월 ○일** — 학습자가 고가 온라인 강의 랜딩 앞에서 망설일 때, **스스로 판단할 근거**를 한 화면에 모아 주는 도구 **「○○」(가칭)** 이 오늘 정식 서비스를 시작했다고 발표했다.

○○은 학습자가 **본인이 선택한 랜딩 페이지 URL**을 붙여넣기만 하면, **마케팅 문구와 실제 커리큘럼 사이의 간격**, **불안을 부추기는 표현의 분리**, 그리고 **유튜브·인프런·검증된 아티클**로 이어지는 **무료·저가 학습 경로**를 **중립적인 신호**로 제시한다. 제품은 **“사지 마라”고 말하지 않으며**, 코호트·멘토링 등 **유료가 정당할 수 있는 경우**도 학습자가 스스로 무게를 달 수 있도록 **정보 구조**만 돕는다.

초기에는 **웹 온보딩**으로 신뢰를 쌓은 뒤, **브라우저 확장**으로 일상 탐색에 자연스럽게 이어지는 **두 단계 경험**을 제공한다. 회사는 “한국 온라인 교육 시장의 **FOMO 소비**를 줄이고, **정보 대칭**을 높이는 것이 목표”라고 밝혔다.

### B.2 완성된 상황 — 사용자 하루 시나리오 (내러티브)

**민지(29, 이직 준비)** 는 야간에 반복해서 뜨는 부트캠프 광고를 보다가, 결국 랜딩 페이지를 열어 놓은 채 가격표만 몇 번이나 읽었다. “지금 안 사면 늦는다”는 문장이 머릿속을 맴돌았다. 대신 그녀는 북마크해 둔 **○○ 웹**에 URL을 붙여 넣었다.

몇 초 뒤 **사이드 패널**이 열리며, 왼쪽은 익숙한 랜딩, 오른쪽은 **정리된 신호**였다. 상단에는 **“마케팅에서 말하는 성과”**와 **“커리큘럼에 실제로 적힌 단원”**이 나란히 비교되어, 과장되는 부분이 한눈에 들어왔다. 그 아래 **FOMO 문장만 모은 블록**에는 각 문장 옆에 **왜 불안을 자극하는지** 한 줄씩 붙어 있었고, 민지는 웃으며 “이건 문장 공장이네”라고 중얼거렸다. 가격이 높게 잡힌 탭에서는 **생소한 용어**가 **짧은 설명**과 함께 풀렸고, **비슷한 목표를 달성할 수 있는 무료 영상·인프런 입문 강의·공식 문서 링크**가 카드 형태로 정렬되어 있었다.

민지는 **결제 버튼을 누르지 않은 채**로도 오늘 밤 할 일이 생겼다: 링크 두 개를 열어 실제로 들어보고, 일주일 뒤에도 필요하면 그때 **유료의 구조적 가치(코호트 등)** 를 다시 비교하기로 했다. 주말에는 같은 도구의 **확장 프로그램**을 깔아, 앞으로 랜딩을 열 때마다 **한 번의 클릭으로 같은 패널**을 부를 수 있게 해 두었다. 그녀의 한 줄 평은 이랬다: **“사주는 게 아니라, 나한테 판단권을 돌려준 느낌.”**

## Part C — 1-Pager (지정 양식)

### Observation : 현재 상황

- 국내에서 **고가 강의·부트캠프**에 대해 **FOMO 마케팅·과대 포장·빈 콘텐츠**에 대한 사회적 불신(“강의팔이” 인식)이 강함.
- 유저는 광고·랜딩을 통해 **생소한 용어**와 **조급함**을 동시에 경험하고, **가격** 때문에 결정을 미루거나 충동 구매를 한다.
- **유튜브·인프런·좋은 아티클** 등 대안은 존재하나, **해당 랜딩의 문장·커리큘럼과 구조적으로 대조**하기 어렵다.

### Problem Statement : 현재 상황의 문제

- **정보 비대칭:** 마케팅 주장과 실제 학습 내용·난이도의 **갭**을 스스로 정리하기 어렵다.
- **FOMO:** 시간 제한·비교·결핍을 부추기는 문장이 **감정적 결정**을 유도한다.
- **대안 발견 비용:** 무료·저가 경로를 찾아도 **“이 강의가 말하는 것과 같은 목표인지”** 매칭이 번거롭다.

### Root Cause (가설적인) : 문제가 되는 원인

- 랜딩은 **전환율 최적화**를 위해 **감정·긴급성**에 최적화된 카피가 표면에 노출되고, **커리큘럼·선행지식**은 상대적으로 읽히기 어렵다.
- 플랫폼 간 **비교 표준**이 없고, 학습자는 **동일 목표를 달성하는 대체 경로**를 한 화면에서 검증하기 어렵다.

### Target Customer : 타겟 사용자

- **고가 온라인 강의/부트캠프 랜딩**을 보고 **망설이거나 FOMO를 느끼는** 성인 학습자(이직·부업·스킬업 등).
- **충동 결제를 줄이고** 스스로 근거를 갖고 싶은 사람.
- (2차) 동일 패턴을 **반복 탐색**에서 쓰고 싶어 **브라우저 확장**까지 받아들일 만큼 B에서 효용을 본 사람.

### Jobs to be done : 원하는 결과

#### Situation : 타겟 사용자가 어떤 상태여야 하는가

- **본인이 선택한 랜딩 URL**을 가진 상태에서, **별도 설치 없이(B)** 또는 **설치 후(A)** 로 **몇 분 안에** 랜딩과 **나란히** 분석 패널을 볼 수 있다.

#### Motivation : 타겟 사용자가 어떤 동기를 가져야 하는가

- “**속지 않고** 같은 목표를 더 합리적인 비용·속도로 달성할 수 있는지 확인하고 싶다.”
- “**FOMO 문장**과 **실제 배울 것**을 분리해 보고 싶다.”

#### Expected Outcome : 타겟 사용자가 어떤 행동/생각을 해야 하는가

- **구매 전:** 갭·FOMO 목록·대안 링크를 바탕으로 **추가 탐색(무료 자료 시청 등)** 을 하거나, **유료의 비콘텐츠 가치**를 스스로 재평가한다.
- **제품에 대한 기대:** “**결정은 내가** 하되, **근거는 제품이 정리해 준다**”고 느낀다.
- (선택) B 이후 **A 설치**로 같은 패턴을 **반복 여정**에 적용한다.

### Hypothesis : 가설

- 유저가 **URL 한 번으로** **갭 + FOMO 분리 + 가격대별 풀이·대안 링크**를 보면, **충동 결제 감소**와 **만족도 있는 학습 경로 선택**이 동시에 늘어난다.
- **B→A** 순서가 **신뢰·효용** 없이 확장만 노출하는 것보다 **전환과 리텐션**에 유리하다.
- **중립 신호 + 면책** 정책이 장기적으로 **법적·평판 리스크**를 낮추고 브랜드 신뢰를 높인다.

### Success metrics : 성공 지표

| 지표 | 정의(초안) |
|------|------------|
| **첫 가치 도달률** | URL 제출 후 사이드 패널에서 **갭 + FOMO 블록**이 모두 렌더된 세션 비율. |
| **행동 전환** | 패널 노출 후 **대안 링크 1개 이상 클릭** 또는 **세션 내 체류/재방문** 비율. |
| **태도** | 설문: “구매 결정에 도움이 됐다” 긍정률, “과대 단정이 불편했다” 부정률(낮을수록 좋음). |
| **B→A** | B 방문자 대비 **A 설치율** 및 A 사용자의 **주간 재사용**. |
| **안전** | 악성/민감 오분석 **신고율** 및 대응 SLA(운영 정의 후). |

### Test Plan : 실험 계획

1. **MVP 범위:** 온보딩 웹 + URL 붙여넣기 + 사이드 패널(갭, FOMO 분리, 가격 반영 정책 v0, 외부 링크, 면책).
2. **피조사자:** 실제 망설였던 랜딩 URL을 가진 사용자 **N명**(비공개 베타).
3. **방법:** 사전·사후 설문 + 화면 녹화/인터뷰(동의 하에) + 클릭 로그.
4. **대조:** “URL 없이 자유 탐색” vs “패널 사용” **전후** 자기 보고 충동도(간이 척도).
5. **A 실험:** B 효용 확인 후 소수에게만 확장 베타 배포, 권한 범위 A/B 문구 테스트.
